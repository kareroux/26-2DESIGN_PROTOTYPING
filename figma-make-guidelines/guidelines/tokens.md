# Tokens

모든 값은 globals.css의 CSS 변수로 쓴다. Tailwind에서는 `bg-[var(--surface)]`, `text-[var(--ink)]`처럼 참조한다.

## Color (짙은 파란 바탕 한 테마)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--surface` | #0a1a2f | 페이지 바탕. 모든 텍스트와 금붕어는 이 위에 |
| `--ink` | #eef2f8 | 본문, 제목, 제품 컨셉. 보조 버튼 채움 |
| `--ink-muted` | #94a6c0 | 보조 텍스트, 단위, 축, 자리표시 |
| `--line` | #1e3350 | 차트 그리드 전용 |
| `--brand` | #ff8a3d | **메인 컬러 슬롯 (오렌지).** 주 버튼, 토글 ON, 차트 선, 포커스 |
| `--on-brand` | #241000 | brand 위 글자 |
| `--off` | #4a5d7d | 토글 OFF 트랙, 연결 안 됨 점 |
| `--fish-glow` | #ffb066 | 센서값에 비례하는 금붕어 주변 빛 |
| `--status-on` | #4cc38a | "연결됨" (글자와 함께) |
| `--danger` | #f97066 | 오류 (글자와 함께) |

메인 컬러를 바꾸면 `--on-brand`가 `--brand` 위 4.5:1 이상, `--brand`가 `--surface` 위 3:1 이상인지 확인.

## Type

- 메인 폰트 IBM Plex Sans KR (400, 500, 600): 모든 글자
- 서브 폰트 고운바탕 Gowun Batang (700): 제품 이름, 센서값 숫자에만
- 자간, 행간은 지정하지 않는다 (폰트 기본값)

| 이름 | 폰트 / size / weight | 용도 |
| --- | --- | --- |
| display | 서브 / 40 / 700 | 제품 이름 (모바일 24) |
| value | 서브 / 48 / 700, tabular-nums | 금붕어 아래 현재 센서값 |
| body | 메인 / 16 / 400 | 제품 설명, 빈 상태 문구 |
| label | 메인 / 14 / 500 | 버튼, 상태, 컨트롤 이름, 제품 컨셉 |
| caption | 메인 / 12 / 400 | 축, 단위, 켜짐/꺼짐 |

## Spacing (px)

`--space-1` 4, `--space-2` 8, `--space-3` 12, `--space-4` 16, `--space-6` 24, `--space-8` 32, `--space-12` 48

- 페이지 여백: 모바일 위아래 32, 좌우 16 / 웹 위아래 48, 좌우 32
- 섹션 사이: 모바일 32 / 웹 48
- 컨트롤 행 사이: 24

## Shape

- 사각 요소: radius 0, 테두리 없음, 그림자 없음
- 원형 요소(상태 점)만 원

## Breakpoint

768px 미만 1열(스마트폰), 이상 금붕어 아래 컨트롤(1) + 차트(2) 2열. 콘텐츠 최대 폭 1120px 가운데 정렬.
